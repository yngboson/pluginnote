# 작업 계획 및 결정 기록

기획서(공학용 확장형 노트 앱, 2026-10-31) 기반. 앱 이름은 가칭 `pluginnote`.

## 결정 사항

| # | 항목 | 결정 | 근거 / 비고 |
|---|------|------|-------------|
| D1 | 1차 플랫폼 | **iPad 먼저**, 안드로이드는 이후 | 사용자 결정. Rust 코어는 공통이라 영향 없음 |
| D2 | AI 플러그인 생성 | **붙여넣기(import)만**. 앱 내장 생성 없음 | 사용자 결정. 비용/키/심사 부담 회피 |
| D3 | 입력 방식 | **모어원 프리셋은 원 + 중심 수직·수평 보조선만.** 숫자/키보드 입력·드래그 핸들은 나중에 플러그인으로 얹을 수 있게 확장 지점만 유지 | 사용자 결정. 확장 지점: `params`(값 모델), `ParamSpec.editor` 힌트, 부속 요소, 스냅 |
| D4 | 라이선스 | **코어 MIT, 플러그인 기본 MIT 또는 CC0** | 사용자 결정. manifest `license` 필드 |
| D5 | 코어 언어 / 바인딩 | Rust 코어 + UniFFI (Swift/Kotlin) | 기획서 §9 |
| D6 | 플러그인 런타임 | QuickJS(rquickjs 0.14), **플러그인당 독립 Runtime/Context** | iOS JIT 제한. 전역 오염 차단 |
| D7 | 플러그인 형식 | `export default definePlugin({...})` ES 모듈. 선언형(JSON)은 API 안정 후 추가 | 모어원/FBD 두 종으로 먼저 API 검증 |
| D8 | 저장 포맷 | UTF-8 JSON, `format`/`format_version`. **값만 저장**, 그림·부속 요소는 파생. 공개 규격으로 간다 | 기획서 열린 질문 → 공개로 가정(되돌리기 쉬움) |
| D9 | 좌표계 | 월드 y-up(수학 좌표), 각도 라디안 반시계 | 공학 도식에 자연스러움 |
| D10 | 객체 모델 | `id/type/params` + 배치(`origin/scale/rotation`). 부속 요소는 렌더가 파생(저장 안 함) | 객체를 옮기거나 값을 바꾸면 부속이 자동으로 따라감 |
| D11 | 결과 노출 | `ctx.readout(label, value, formula)`로 계산식 함께 표시 | 리스크표: AI 계산 오류를 사용자가 검증 |

## 아직 사용자가 정해야 할 것 (지금은 블로커 아님)

- 앱 이름 (가칭 유지 중)
- 공유 레포 운영 주체/도메인, 검증됨 뱃지 심사 주체
- 레포 업로드 시 플러그인 저작권/상업 이용 약관 문구
- 앱스토어 외부 스크립트 실행 정책 확인(출시 전)

## 단계 계획

### 단계 1~3 (이번 작업, 완료 범위)
- [x] Cargo 워크스페이스: `note-core`, `note-plugin`, `note-cli`
- [x] 객체 모델, 레이어, 잉크 획 보관 구조, 기본 도형(line/circle/rect), 변환
- [x] 저장 포맷 직렬화 + 버전 거부 처리
- [x] 그리기 명령(DrawCmd), SVG 내보내기(미리보기/썸네일용)
- [x] 플러그인 호스트: manifest 검증, API 버전 호환, 권한 기본 차단, 파라미터 기본값/범위 검증
- [x] 샌드박스 한도: 시간(인터럽트), 메모리, 스택. 초과 시 해당 호출만 실패
- [x] 플러그인 API v0.1: `circle/line/arrow/arc/polyline/text`, `attach`, `snap`, `readout`
- [x] 모어원 프리셋(원 + 중심 보조선), FBD 화살표(API 과적합 방지용 두 번째 유형)
- [x] `pluginnote check` (업로드 자동 검사의 씨앗), `render`, `doc`
- [x] 통합 테스트 15개

## 알려진 한계 (이번 구현)
- 플러그인 호출은 동기이며 호출 스레드를 막는다(최대 200ms 상한). 스레드 분리는 다음 단계
- `Context::full` 사용으로 JS 표준 라이브러리(`eval` 포함)는 존재. 파일/네트워크/타이머 글로벌은 없음(테스트로 고정)
- SVG 화살촉/텍스트 크기는 미리보기용 근사치
